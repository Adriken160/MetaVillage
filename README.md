# MetaVillage
Este proyecto de Unity se centra en recrear el pueblo de Garganta la Olla, en el que el usuario podría pasear por las calles del pueblo y hablar con los NPC, que realizarán comentarios sobre el pueblo, también contarán la historia de ciertas partes del pueblo, por ejemplo, la iglesia, la casa de las muñecas,... Además, se hace énfasis en la leyenda de la Serrana de la Vera, donde en una parte del pueblo se podrá ver su cueva y escuchar su Romance, a parte de poder hablar con la propia Serrana y que esta te cuente el por qué de su leyenda.

# Script
Se utiliza un Script para que los NPC interactúen con el usuario, pudiéndose comunicar mediante texto o audio. Se usa otro Script para que al acercarse a la cueva se escuche un audio de la leyenda de la Serrana, cuándo te alejas se para de contar la historia.

# Prefabs
Se utilizan prefabs para la creación de la Iglesia, Ermita y Ayuntamiento.

# Assets
Se ha usado Assets para los edificios (), farolas (Street Lights Pack 01), muros (CArtoon Tock Wall), vallas (Realistic Fences Pack), piedras (Low Poly Environment Starter PAck), árboles (Low Poly Tree Pack), NPC (Female Warrior Princess) (Los Poly Character Pack) y el Avatar (Firts Person + Third Person). 

# Materiales
Se han creado los materiales para las Casas, usando como base las texturas del Asset, también hay un material para el agua de los ríos, para las carreteras, las calles y para los diferentes gameobjects de los prefabs.

# Splines
Para los ríos se han usado Splines para darle volumen y poder realizar el contorno de los ríos.
